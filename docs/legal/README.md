Rules for these documents:

- Nothing is invented: names, addresses, providers, retention periods and legal bases stay as
  placeholders until the owner supplies them or a lawyer advises.
- Statements are labelled as a legal requirement (with its source), a recommended practice, a
  product decision, or an unresolved legal question.
- Publishing any legal text on the website changes website text, which is a code change: a feature
  branch, a pull request and the owner's approval (`SECURITY.md` rule 10).
